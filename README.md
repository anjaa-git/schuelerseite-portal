# Schülerseite – Schulportal

Eine zentrale, lokale Schüler-Website für Schule, Lernen und Organisation.

Features:
- Seitenleiste mit Übersichten und Navigation
- Integrierte Schulportal-/WebUntis-Ansicht ohne externe Website-Öffnung
- Stundenplan, Kalender, Notizen, Karteikarten, To-dos, Dateien und KI
- Lokale Speicherung über browserseitiges localStorage
- Responsive Design für Desktop und mobile Geräte

Starten:
1. In den Projektordner wechseln
2. Einen lokalen Webserver starten:
   python -m http.server 8000
3. Im Browser öffnen:
   http://localhost:8000

Alternative:
- `index.html` direkt im Browser öffnen

Dateien:
- `index.html` – Grundstruktur
- `styles.css` – Gestaltung und Layout
- `script.js` – Interaktive Funktionen

Hinweis:
- Die App ist bewusst als lokale, eigenständige Web-App gebaut und öffnet keine externen Schulportale.
- Die Inhalte sind als Beispiel-/Demo-Daten konzipiert und können nach Bedarf erweitert werden.
